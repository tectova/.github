# Tectova

A data-backed fashion editorial and an independent record of the runway.

Tectova connects runway shows, talent and brands in New York, London, Milan and Paris from 2002 onward, and links each record back to its sources.

- Site: [tectova.com](https://tectova.com)
- Methodology: [tectova.com/methodology](https://tectova.com/methodology), with a versioned copy in [tectova/methodology](https://github.com/tectova/methodology)
- Aggregate coverage figures: [tectova/coverage](https://github.com/tectova/coverage)
- Custom data requests: [tectova.com/press](https://tectova.com/press)
- Corrections: [tectova.com/contact](https://tectova.com/contact)

## How to cite

Tectova requests attribution in this form: *Tectova, “[page title],” tectova.com/[path], accessed [date].*

Point the citation to the relevant page on tectova.com, not to GitHub. When quoting a figure, retain the geography, category and as-of date displayed on the supporting page.
